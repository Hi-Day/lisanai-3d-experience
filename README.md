# LisanAI 3D Experience

Independent interactive 3D concept dashboard explaining the LisanAI oral assessment workflow.

## Stages
1. Student oral assessment session
2. Speech recognition (audio to transcript)
3. Rubric and Learning Outcome mapping
4. LLM judge evaluation
5. Quality verification and calibration
6. Instructor-facing learning insights

## Run and deploy
Static HTML prototype. Open index.html in a browser or deploy directly to Vercel. Three.js is loaded from jsDelivr CDN.

## Important
This is a visual prototype. It does not connect to LisanAI production APIs or contain student data. Content is illustrative.
